# Code Sprint — mini game điền code C++

Trò chơi dùng 20 bài C++ trong `20CODE_MINIGAME.docx`. Mỗi lượt chọn một bài chưa gặp trong vòng hiện tại và chọn ngẫu nhiên một vị trí trống trong code. Khi đã gặp đủ 20 bài, vòng chọn bắt đầu lại.

## Cách chạy

Mở `index.html` bằng Chrome, Edge hoặc Firefox. Trang chạy trực tiếp trên máy, không cần cài đặt, kết nối mạng hay khởi động server.

## Cách chơi

Kéo một thẻ đáp án vào ô trống trong code, rồi nhấn **Kiểm tra**. Trên màn hình cảm ứng, chạm thẻ rồi chạm ô trống. Trò chơi báo đúng/sai trước khi sang câu tiếp theo.

## Nội dung

Gồm 20 chủ đề: nhập xuất, biến và phép tính, chia lấy dư, vòng lặp `for`, `while` và `do...while`. Mỗi bài có nhiều vị trí có thể khuyết để các lượt chơi thay đổi.
